# PROJECT RESCUE MOTHER: 2D NARRATIVE PUZZLE ENGINE

## 1. Project Overview
A 2D web/mobile interactive rescue-and-renovation puzzle game built with HTML5 Canvas / Phaser.js. Players solve contextual puzzles using drag-and-drop mechanics to save a freezing mother and baby, transforming a dilapidated cabin into a warm home.

## 2. Repository Structure & Execution Workflow for Arena.ai
Please execute the project sequentially following these step-by-step documentation files:

- `01_GDD_CORE_MECHANICS.md`: Core loop, state machines, win/lose logic, and dropzone interaction matrix.
- `02_ART_GENERATION_PROMPTS.md`: Image generation specs for Arena.ai (Backgrounds, Sprites, Items, Characters).
- `03_TECH_SPEC_ENGINE_CODE.md`: Software architecture, Phaser 3 setup, event-driven drag-drop controller, and scene manager.
- `04_LEVEL_DATA_LEVEL_01.md`: Concrete JSON data structure for Level 1 ("Frozen Cabin Rescue").
- `05_AUDIO_VFX_MONETIZATION.md`: Visual effects, sound triggers, and rewarded ad loops.

## 3. Execution Instruction for Arena.ai
1. Read `01_GDD_CORE_MECHANICS.md` to map dependencies.
2. Generate visual assets using prompts from `02_ART_GENERATION_PROMPTS.md`.
3. Scaffold the codebase based on `03_TECH_SPEC_ENGINE_CODE.md`.
4. Hydrate the engine with level data from `04_LEVEL_DATA_LEVEL_01.md`.
5. Integrate Polish, SFX, and UI flows defined in `05_AUDIO_VFX_MONETIZATION.md`.
