# ART BIBLE & ARENA.AI IMAGE GENERATION PIPELINE

## 1. Style Directive
- **Art Style:** 2D Webtoon game art, clean thick outlines, flat cell-shading, hyper-expressive character facial emotions, vibrant mobile casual aesthetic.
- **Aspect Ratio:** 9:16 portrait mode (1080x1920) for mobile casual displays.
- **Rendering Rules:** Transparent PNG backgrounds for props and characters. Solid layered PNGs for environment scenes.
